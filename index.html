Module 01

函数作图

输入 f(x)，实时绘制曲线。支持 sin、cos、exp、sqrt、^ 等运算；可叠加多条函数对比观察。

Module 02

导数与切线

拖动 x₀，观察切线如何随切点移动。切线的斜率即为该点的导数值 f′(x₀)。

Module 03

积分与黎曼和

把曲线下方划分成小矩形，再让误差趋于零。调节分割数 n，观察矩形面积如何逼近真实积分。

Module 04

极限与逼近

从两侧出发，再降到公式。观察 x 趋近 a 时 f(x) 的走向——点击播放看探针自动逼近。

Module 05

傅里叶级数

用有限个正弦波叠加逼近方波。增大项数 N，观察吉布斯现象外的拟合效果。

Module 06

3D 曲面

输入 z = f(x, y)，拖拽旋转查看立体曲面。支持 sin、cos、sqrt、exp、^ 等。
