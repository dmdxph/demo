# 高数可视化 · Calculus Viz

一个零构建的单文件交互式高等数学可视化工具（纯前端 + CDN）。

## 功能模块
- **函数作图**：输入 f(x)，实时绘制 2D 曲线，支持缩放/平移、多函数叠加
- **导数 / 切线**：拖动 x₀，切线跟随移动，实时显示斜率（导数值）
- **积分 / 黎曼和**：调节分割数 n，看矩形如何逼近曲线下面积
- **极限动画**：x 趋近某值时函数值的变化
- **傅里叶级数**：用少量正弦波逼近方波
- **3D 曲面**：z = f(x,y) 的立体表面

## 部署
纯静态站点，无需构建：
- Vercel：导入本仓库即可（Framework 选 Other / 静态）
- 或直接把本目录拖到 Vercel 部署

技术：Plotly.js（绘图）、KaTeX（公式），均通过 CDN 加载。
